# Prizepulse — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Departmental chief economist / modeller

- As a chief economist, I want to clone the canonical 10.3% scenario and change only uptake speed, so that I can see policy-sensitive deltas without rebuilding the model.
- As a modeller, I want channel contributions itemised (productivity, quality, variety, time saved), so that ministers cannot quote the headline without the composition.
- As a modeller, I want every output stamped “potential vs baseline,” so that we do not misuse the tool as a point forecast.

### Industrial strategy / regional official

- As a regional official, I want GDP and household spending-power side by side for my nation, so that NI’s lower GDP % is not misread as no household benefit.
- As a strategy lead, I want sector lenses for health, automotive and financial services, so that sector deals target where product enhancement concentrates.
- As an official, I want phase charts through 2030, so that near-term productivity programmes are not judged on consumption-side timing.

### Labour market / skills analyst

- As a labour analyst, I want displacement and creation nets under the same assumption set, so that automation headlines are balanced with demand-driven jobs.
- As a skills official, I want autonomous-vehicle-style regulatory job categories flagged when no-human-in-loop uptake rises, so that training pipelines can anticipate them.

### Scrutiny / NAO analyst

- As a scrutiny analyst, I want assumption diffs between two scenarios, so that I can test whether a spending claim is robust.
- As a scrutiny analyst, I want appendix caveats embedded in exports, so that exogenous shock limitations travel with the numbers.

### Platform administrator

- As a platform administrator, I want conversion tables (AI Index → variety/utility/time) versioned, so that methodological changes are explicit.
- As an administrator, I want access control on unpublished sector assumptions, so that market-sensitive inputs are not public by default.
- As a data steward, I want accredited-environment hooks for any future microdata extensions, so that aggregate APIs stay clean.
